01 ｜ いまの1日

社長の時間は、
「社長にしかできない仕事」に
使えていますか？

  • 現場に立ちながら、合間にメールとLINEの返信
  • 夜になってから、ブログ・SNS・お知らせの文章づくり
  • 月末は数字の集計と、資料の作り直し
  • 「いつか考えよう」と思っている新しいことが、ずっと「いつか」のまま

忙しさの多くは、社長でなくてもできる作業でできています。

02 ｜ CLAUDE CODE とは

「答えるAI」から、
「代わりに動くAI」へ。

これまでのチャットAI 聞けば、答える

答えをコピーして、貼りつけて、保存して、送る。最後の作業は人がやる。

CLAUDE CODE 頼めば、やっておく

パソコンの中で、ファイルを作る・直す・まとめる・決まった時間に動かす。言葉で頼むだけで、作業そのものを進めてくれる。

プログラミングの知識はいりません。日本語で頼めば動きます。

03 ｜ できること

社長の「作業」は、
ほとんど任せられます。

文章を書く

ブログ、SNS、お客様へのお知らせ、お礼のメール。

例：箇条書きのメモから、お知らせ文を3案

資料をつくる

提案書、チラシ、契約書のひな形、ウェブページ。

例：このページも、AIと一緒に作りました

数字をまとめる

売上・予約・広告・SNSの数字を集めて、比べて、要点だけ。

例：毎週月曜の朝、先週の数字が届く

連絡を整える

メールの下書き、会議の記録と要点、予定の整理。

例：打ち合わせの記録を、翌朝には整理済みに

決まった時間に回す

毎朝・毎週の決まった作業を、寝ている間に自動で。

例：毎朝、業界ニュースの要点がメールで届く

覚えておく

会社のルール、過去の判断、お客様とのやりとりをノートに残して、次に活かす。

例：「前回どうしたっけ？」をAIに聞ける

05 ｜ 問い

残った時間で、
何をしますか？

時間は、使い道を決めていないとまた作業で埋まります。
気になるものを選んでみてください（いくつでも）。

06 ｜ あなたの答え

1日2時間あったら、
最初の1週間で何をしますか？

書いた内容は、この端末の中にだけ残ります（送信はされません）。

答えが出た人ほど、AIを入れたあとに時間が本当に変わります。

07 ｜ 始め方

まずは3つだけ。

1

仕事を書き出す

1週間の仕事をぜんぶ並べて、「自分にしかできない」「人に任せる」「AIに任せる」「やめる」に仕分けます。

2

AIに渡す

「AIに任せる」に入った仕事から1つずつ。社長のパソコンで、言葉で頼める状態をつくります。

3

空いた時間を先に予約

空いた時間に、さっき書いた「やりたいこと」を先に入れておく。これで時間が作業に戻りません。

08 ｜ さいごに

AIは、時間をつくる道具です。
何に使うかを決めるのは、社長です。

「何を任せられるか」の仕分けから、一緒にやります。
まずは30分、あなたの1週間の仕事を見せてください。
